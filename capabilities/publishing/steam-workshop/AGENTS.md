# Steam Workshop 发布规则

继承仓库根 `AGENTS.md`。

- 项目配置必须通过 `schemas/project-profile.schema.json` 的完整验证及语义检查。
- 默认执行只读预检；只有显式 `-Publish` 才能打开上传器或修改 Workshop。
- 发布前必须验证 Git 门禁、Workshop ID、预期标题、候选文件和远端预览图。
- 远端预览图必须下载留证并在发布前后核对；不得用开发目录图片意外覆盖。
- 通用编排器只能保留一个上传触发调用点；每个变体至多触发一次 Upload。
- Upload 触发后只允许轮询远端状态；超时、失焦或状态不明时不得自动再次上传。
- 证据目录必须保留发布清单、远端预览图和适配器提供的必要证据。
