# 玩家只读诊断采集器

状态：实现与验证完成；用户于 2026-10-26 明确授权发布，纳入工具集 0.4.0。

## 目标与边界
先支持猎人蓝图，通过已知发布 ZIP 内的 manifest 核对安装文件，输出可分享的本地诊断包。
复用 PowerShell 7，无新增依赖。不调用 Lua、SDK、开发诊断器，不写游戏目录、不启动游戏、不联网。
采用 CLI + 纯采集模块；不引入 GUI 或通用插件执行机制。

## 契约与兼容性
- 输入：游戏目录、可信本地发布 ZIP、新建输出目录。游戏路径由用户传入，不能猜测安装盘。
- 发行包 manifest 是现有 Hunter Blueprint 格式；入口将其转换为 schemaVersion=1 的内部报告契约。
- 发布包只读取 manifest，不解压运行文件，不执行任何内容。限制清单大小、数量、路径和 SHA-256。
- 只核对本 Mod Lua 和字体；README/许可证不作为游戏安装必需项。
- 不跟随输入/输出路径中的重解析点；输出须位于游戏目录以外且不得覆盖已有目录。
- 文件缺失/不符/不可读分别记录；未观察到运行状态时为 unknown，不把磁盘匹配当作运行时通过。
- 日志仅读取白名单 re2_framework_log.txt 的末尾，最多 256 KiB，允许并发读取；不自动重试。
- 默认不输出原始日志文本。仅提取固定错误类别及时间范围之外的行序号，避免未知玩家身份进入包。
- 未匹配的日志不等于无错误；报告明确采样和分类局限。框架版本若不可可靠读取则 unknown。
- 不导出个人配置、存档、完整 Mod 清单、玩家姓名、Steam ID、绝对路径或异常消息。

## 验收标准
正常文件、缺失、混装、额外 Lua、中文路径、缺日志、共享写占用、独占占用、日志上限、未知版本均有明确结果。
恶意路径、空清单、非法哈希、输出覆盖、输出指向游戏、junction 越界拒绝。
输入树哈希前后不变；诊断包不含测试植入的姓名、凭据、玩家标识或绝对路径。
报告字段区分 installation 与 runtime；未知项不写 passed。
