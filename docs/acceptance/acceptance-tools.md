# 通用验收工具验收计划

范围：提炼场景编排、布局诊断和制品证据门禁，不引入游戏专用坐标、引擎或自动发布动作。
环境：Windows、PowerShell 7；适配器为项目提供的受信任 PowerShell 模块。

|编号|操作与输入|预期结果|验证方式|状态|
|---|---|---|---|---|
|A01|执行两个场景，返回已就绪与预期状态|逐项断言、记录候选哈希和证据，恢复原设置|测试适配器集成|通过|
|A02|场景未就绪或就绪后状态不符|有界超时或失败，不放行，仍恢复|故障注入|通过|
|A03|运行时身份或候选哈希不符|拒绝错误场景/旧安装副本|故障注入|通过|
|A04|场景或恢复操作异常|记录失败与恢复状态，不冒充通过|故障注入|通过|
|L01|实测文字宽高超过控件、控件超出画布|报告裁切或越界及元素编号|几何测试|通过|
|L02|两个普通内容矩形相交|报告重叠|几何测试|通过|
|L03|弹出菜单覆盖普通内容，前景层级正确|允许覆盖；反向层级必须失败|几何测试|通过|
|L04|弹出菜单存在而背景仍接收输入|报告焦点冲突|几何测试|通过|
|G01|候选、安装副本、运行时、证据均匹配|通过|真实临时文件|通过|
|G02|候选改变或复制旧版passed记录|拒绝|真实临时文件|通过|
|G03|必需项失败/未验证，或证据缺失/被修改|拒绝|真实临时文件|通过|
|G04|来源提交或运行时身份不符|拒绝|真实临时文件|通过|
|R01|执行既有全套测试|既有能力不回归|仓库测试|通过|
|R02|安装新版本、远端源码及附件核验|版本、SHA和安装副本一致|安装与发布核对|未验证|

自动化适配器测试不等于真实游戏、实体手柄或人工视觉验收。场景工具不生成manual passed；视觉总览仍需要人工判断。验收证据必须绑定最终候选，不能沿用旧哈希记录。

自动测试记录：新增工具先确认模块缺失导致测试失败，再实现并完成回归；场景适配器属于模拟，几何诊断采用合成输入，制品门禁使用真实临时文件。仓库全套测试通过。R02 在发布后以 GitHub Release 和本机安装核验报告补充证据。
