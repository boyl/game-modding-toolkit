# 0.4.0：猎人蓝图玩家只读诊断

新增面向 Hunter Blueprint 的安装检查与本地诊断包，减少反馈问题时反复确认版本和安装位置的步骤。

- 对照可信本地发行 ZIP 清单，核对 Mod Lua 与字体，区分匹配、缺失、不符、不可读及额外 Lua 残留。
- 日志末尾最多读取 256 KiB，仅导出固定错误类别与采样行号，最多 100 条；不导出原始日志、个人路径、配置和存档。
- 不联网、不上传、不执行游戏代码，不启动/关闭游戏，不写游戏目录。
- 拒绝非法清单路径、重解析点及覆盖输出；运行时和框架版本未验证时明确显示 unknown。

## 下载与使用

下载 `GameModdingToolkit-0.4.0.zip`，解压到独立目录。需要 Windows 和 PowerShell 7。
准备可信 Hunter Blueprint 发行 ZIP，创建输出父目录，再运行：

```powershell
pwsh ./capabilities/diagnostics/Collect-HunterBlueprintDiagnostic.ps1 -GamePath 'D:/SteamLibrary/steamapps/common/MonsterHunterRise' -ReleaseArchive 'D:/Downloads/HunterBlueprint-1.1.0.zip' -OutputDirectory 'D:/Reports/hunter-check-001'
```

末级输出目录必须不存在，且位于游戏目录之外。查看说明.txt 和 report.json，按需手动分享 diagnostic.zip。
升级工具集时解压到新目录，保留旧版即可回退；无需改动游戏安装或已有项目配置。

## 验证与限制

20 组诊断场景和工具集全套回归通过；此前独立工具包解压后测试通过。
本机 Hunter Blueprint 1.1.0 的 24 个运行文件/字体匹配，无额外 Lua；游戏文件版本 16.0.2.0。
日志为采样分类，没有完整堆栈，无匹配不代表没有错误。文件哈希匹配不代表游戏功能正确，也不认证发行 ZIP 来源。
首版未验证其他电脑，不把本轮结果推广到其他 Mod 或运行时。未修改已有 Workshop 发布和 VFX 能力。
