# Monster Hunter Rise 工作规则

- 本目录只保存《怪物猎人：崛起：曙光》的通用能力、契约和公开示例；具体 Mod 的视觉素材、动作表和发布身份留在项目仓库。
- 修改运行时前先固定目标游戏版本、REFramework 版本、武器类型、动作银行、Provider Container 与命中来源契约。
- 特效派发默认仅限本地，`network_sync` 必须为 `false`；不得修改伤害、动作、判定、网络状态或存档。
- 一次性效果和持续实例必须显式区分。持续实例在动作切换、动作重启、脚本重载及场景退出边界释放。
- 运行时计数只能证明逻辑发生；实际可见效果仍需修炼场截图或人工视觉验收。
- 不提交游戏原始资源、参考 Mod 附件、第三方 DLL、个人路径或私人存档。
